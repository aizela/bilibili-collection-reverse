# B站合集反转

![B站合集反转图标](icons/icon128.png)

当前版本：1.2.1。

Chrome / Edge 的 Manifest V3 扩展。分别控制每个合集小节内部的视频顺序，以及上方小节标签的顺序。播放器的「下一集」「上一集」和自动连播一起采用新顺序。

**两个开关相互独立，可以只开一个，也可以同时开启。一个视频内部的多个分 P 始终保持原顺序。**

## 安装

1. 在 GitHub 仓库点击「Code → Download ZIP」并解压，或者使用 Git 克隆本仓库。
2. Chrome 地址栏输入 `chrome://extensions`（Edge 输入 `edge://extensions`）。
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目文件夹。
5. 刷新已经打开的 B站视频页。
6. 在合集标题下，或浏览器扩展菜单里的「B站合集反转」弹窗，按需打开「反转小节内视频」「反转小节顺序」。

不需要安装 Node.js，不需要运行构建命令。整个目录直接加载即可。请保留该文件夹，不要在加载后移动它。

### 从旧版本更新

在 `chrome://extensions`（或 `edge://extensions`）找到本扩展，点击卡片上的重新加载按钮，然后刷新已经打开的 B站页面。1.2.0 改为标签页会话设置，不再读取旧版 `chrome.storage.local` 的持久设置，首次使用时两个开关均默认关闭。

## 使用

- 两个开关默认关闭。分别关闭时恢复对应的原始顺序，全部关闭时完整恢复 B站原始顺序。切换开关不会换掉正在播放的视频。
- 开关设置保存在当前 B站标签页的 `sessionStorage`，各标签页独立。同一标签页刷新或站内切换视频后保留；关闭标签页结束会话后清除，新会话默认关闭。浏览器复制标签页、恢复关闭的标签页或恢复浏览会话时，可能按浏览器自身规则继承或恢复 `sessionStorage`。
- 扩展弹窗只控制当前标签页，并与该页内的开关同步。在非 B站视频页使用弹窗时，会提示打开视频页；更新扩展后若连接失败，请刷新视频页。
- 开启时同步调整合集显示和原生播放队列。请在 B站播放器设置中开启自动连播；扩展不替你改变这个偏好。
- 「反转小节内视频」只反转每个小节内部的视频。例如「风云3」从 `20、19、…、1` 变为 `1、2、…、20`，不影响小节排列。
- 「反转小节顺序」只反转上方小节标签。例如「风云1 / 风云2 / 风云3第三部分 / 风云3第二部分 / 风云3」变为「风云3 / 风云3第二部分 / 风云3第三部分 / 风云2 / 风云1」，不影响各小节内部的视频排列。
- 同时打开两个开关，将同时反转小节与小节内视频。跨小节播放同步采用当前的小节排列。
- 合集本身缺少的视频不会补齐；末集、循环播放和推荐续播遵循 B站播放器自己的设置。

## 权限与兼容性

仅在 `https://www.bilibili.com/video/*` 页面运行，不再申请 `storage` 权限。设置由该页面的 `sessionStorage` 保存；扩展弹窗通过消息读取和修改当前标签页设置。没有后台服务、外部请求、统计上报或远程代码。

适配当前桌面版 B站 VideoPod 合集组件与 Nano 播放器。普通单视频、多 P 列表、番剧、收藏夹以及 UP 主空间的合集管理页不在本扩展范围。B站修改页面内部接口后，可能需要更新适配；无法识别播放器时页面开关会提示，不会只反转显示列表。

## 开发与验证

代码无第三方依赖。使用 Node.js 运行：

```sh
npm test
```

- `core.js`：独立调整小节与视频顺序的纯数据变换、原始数据快照与幂等恢复，始终保留分 P 顺序。
- `page.js`：页面主世界适配，更新 Vuex 合集模型与原生播放器队列，监听站内换集。
- `content.js`：隔离世界的设置与页内开关。
- `session-store.js`：当前 B站标签页的会话设置，只读写扩展专用的 sessionStorage 键。
- `popup.*`：扩展弹窗。
- `tests/`：数据变换及页面适配回归测试。

现场验证采用单独的 B站测试标签注入扩展的页面代码；不会自动将本扩展安装进浏览器。具体结果见 `TESTING.md`。
